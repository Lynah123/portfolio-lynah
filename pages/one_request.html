ONEREQUEST

ONEREQUEST est une application web moderne développée avec Symfony pour le backend et ReactJS pour le frontend. Elle est conçue pour permettre aux entreprises de gérer en ligne l’ensemble de leurs demandes internes, de manière centralisée, fluide et standardisée. Une fonctionnalité de prise de rendez-vous est également intégrée pour faciliter les échanges avec les différents services.

  1. Fonctionnalités principales :

    Soumission de demande :

    Les utilisateurs peuvent soumettre différentes demandes en ligne, en fonction du type de besoin et du département concerné.

    Prise de rendez-vous :

    Une section dédiée permet de planifier des rendez-vous avec les départements concernés, selon la disponibilité et le type de demande.

    Gestion des structures de l’entreprise :

    L’application gère les départements, les sites (par région et commune), les catégories et domaines d’entreprise, ainsi que les niveaux hiérarchiques.

    Types de demandes :

    Les types de demandes sont paramétrables par site, permettant une grande flexibilité selon la structure de l’entreprise.

    Traitement des demandes :

    Chaque demande suit un processus de traitement défini selon : le département concerné, le site d’affectation, le type de demande, et le niveau hiérarchique associé.

    Interface intuitive et responsive :

    L'application offre une navigation fluide sur ordinateur, tablette et mobile, assurant une expérience utilisateur optimale.

Objectifs de l’application :

1- Centraliser et standardiser la gestion des demandes internes.

2- Optimiser la communication entre les départements via la prise de rendez-vous.

3- S’adapter aux structures variées des entreprises (par site, région, type de demande, etc.).

4- Suivre les traitements des demandes selon les flux définis par département et hiérarchie.

5- Offrir une plateforme performante, moderne et facile d’utilisation.
